# الدليل التنفيذي العربي — ArSL V5

**اسم المشروع:** التعرف على حروف لغة الإشارة العربية باستخدام التعلم العميق والتعلم بالنقل وتصنيف الميزات.

**المدخل:** صورة RGB لحرف إشارة واحد. **المخرج:** الفئة الأقرب من 31 فئة وأفضل خمسة توقعات. **الأداء المسجل:** 88.31% على اختبار استكشافي من 744 صورة.

## التشغيل

1. فك ضغط الحزمة كاملة دون تغيير أسماء الملفات.
2. ثبّت Python 3.11 وأنشئ بيئة افتراضية.
3. ثبّت المتطلبات: `python -m pip install -r requirements.txt`.
4. تحقّق من الأوزان: `python scripts/verify_assets.py --strict`.
5. شغّل: `python app.py`.
6. افتح `http://127.0.0.1:7860`، ثم ارفع صورة أو التقط صورة بالكاميرا.

لا يحتاج التشغيل إلى إعادة التدريب. عند العمل من الهاتف عبر رابط عام، يلزم استضافة Python؛ صفحات GitHub Pages الثابتة لا تشغّل TensorFlow.

## سير العمل العلمي

- دراسة مجموعة صور AASL وتنظيف الصور غير الصالحة وتنظيم تسميات الفئات.
- تقسيم البيانات إلى تدريب وتحقق واختبار، مع التنبيه إلى أن فصل الأشخاص غير مضمون.
- الاستفادة من MobileNetV2 وEfficientNetV2B0 بعد Fine-Tuning في المراحل السابقة.
- استخراج متجه ميزات 1280 من كل شبكة، ثم دمجهما للحصول على 2560 قيمة.
- إجراء `L2 normalization` ثم `PCA` إلى 128 بُعداً، وتدريب `SVM` بنواة `RBF`.
- دمج درجات SVM مع متوسط درجات الشبكتين بالنسب الأصلية المحفوظة في V5.
- قياس Accuracy وMacro F1 ودقة كل فئة، وبيان القيود البحثية.

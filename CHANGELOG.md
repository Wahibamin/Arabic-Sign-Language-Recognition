# Change Log

## 1.0.0 — November 2026

- Packaged the recorded V5 model ensemble without retraining or altering inference weights.
- Created a formal Arabic Gradio interface with photo upload, webcam capture, top-five predictions, and scope disclaimer.
- Added data, methodology, evaluation, model card, licensing, deployment and reproducibility documentation.
- Added static model checks, offline logic tests, CI workflow, and SHA-256 manifest.
- Preserved original V5 training notebook and presentation notebook for academic review.

**Historical experiments:** V1 → V2 → V3 → V5 improved the recorded exploratory test accuracy from 59.95% to 88.31%; the V4 tuning attempt was not accepted. This history is documented as observational, not as independent cross-version evaluation.

# Citation and attribution

If you use this repository academically, cite the original AASL dataset and describe your own V5 implementation and evaluation separately.

Dataset paper:

> M. Al-Barham et al., *RGB Arabic Alphabets Sign Language Dataset*, arXiv:2301.11932 (2023).
>
> https://arxiv.org/abs/2301.11932

Dataset repository:

> https://www.kaggle.com/datasets/muhammadalbrham/rgb-arabic-alphabets-sign-language-dataset

Model scores in the repository are **exploratory** and are not claimed as published benchmark results. Please verify dataset/model licensing and original authorship before republishing pretrained/model-derived artifacts.

# ملاحظات الخصوصية والأمن

- تُستخدم الصور التي يرفعها المستخدم لتوليد تنبؤ خلال جلسة التطبيق. لا يتعمد الكود حفظ الصور في المستودع أو إرسالها إلى جهات تسويق.
- Gradio والخادم المستضيف قد يعالجان الملفات في مجلدات مؤقتة. تحدد سياسة المنصة مدة الاحتفاظ وأذونات الوصول.
- لا تُرفع صور لأشخاص آخرين دون إذن.
- لا تتضمن الحزمة قاعدة صور AASL الخام.
- لا تفتح ملف `v5_classifier.joblib` إلا إذا كان موثوق المصدر؛ يستخدم joblib آلية إلغاء تسلسل يمكنها تنفيذ تعليمات أثناء التحميل.
- لا توجد مفاتيح API أو رموز وصول ضمن التطبيق. لا تضفها إلى GitHub.
- هذا نموذج أولي أكاديمي، وليس أداة معتمدة لاتخاذ قرارات مهمة.

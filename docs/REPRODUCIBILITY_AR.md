# قابلية إعادة الإنتاج والتحقق

## الموجود في الحزمة

- أوزان MobileNetV2 وEfficientNetV2B0 بعد التدريب (`.keras`).
- مصنف SVM مع PCA (`.joblib`) وملف ترتيب الفئات.
- إعداد دمج V5 الأصلي، وملف النتائج `metrics_v5.json`.
- دفتر تدريب V5 ودفتر العرض الرسمي.
- سجل بصمات SHA-256 للملفات الأساسية، وأوامر التحقق منها.

## التحقق من سلامة الملفات

```bash
python scripts/verify_assets.py --strict
```

يساعد هذا الاختبار على كشف فقدان ملف أو تغيّره أثناء النقل. لا يثبت دقة النموذج بمفرده.

## اختبار الاستدلال عند توفر TensorFlow

```bash
python scripts/predict_image.py path/to/sign_photo.jpg
```

ثم أعد تجربة الصورة نفسها عبر واجهة Gradio للتحقق من توافق مسار الاستدلال. لا تستخدم صورة الاختبار المتكرر لتعديل إعدادات النموذج.

## إعادة التدريب الكامل

يمكن مراجعة `notebooks/ArSL_V5_Training_Reproduction.ipynb` لمسار تدريب المصنف V5. وهي تعتمد على وجود الشبكتين وبيانات الصور الأصلية، لذا لا تُعد نسخة مستقلة تعيد جميع تجارب V1–V3 من الصفر.

تكرار الأرقام السابقة يحتاج مصدر البيانات الأصلي، وتوحيد تقسيم الصور والفئات، وضبط بيئة Python وTensorFlow والإصدارات، وعدم استخدام الاختبار أثناء الضبط. تثبيت `SEED` وحده لا يضمن التطابق عبر كل وحدات GPU.

## ملاحظات مهمة

- لا تتضمن حزمة V5 مصفوفة الالتباس الكاملة الخاصة بها، ولذلك لم تُنتج مصفوفة مزعومة.
- الرسوم المسماة V3 تخص V3، والمنحنيات المسماة fine-tune تخص مراحل التدريب السابقة للشبكتين.
- تقييم 88.31% اختبار استكشافي أعيد استخدامه، ويجب إجراء تقييم مستقل على مؤدين جدد قبل الادعاء بإمكانية التعميم.
